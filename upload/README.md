# Калькулятор палубной загрузки

Интерактивный 3D-конфигуратор для расчёта и визуализации палубной загрузки судов.

## Функции

* ➕ Добавление грузов с указанием массы, габаритов и координат
* 📊 Расчёт в реальном времени:

  * Центр тяжести (ЦТ)
  * Метацентрическая высота (GM)
  * Угол крена и дифферент
  * Нагрузка на палубу по каждому грузу
  * Загрузка дедвейта
* 🎨 3D-визуализация:

  * Цветовая индикация статуса (зелёный/оранжевый/красный)
  * Проверка выхода за границы палубы
  * Обнаружение пересечений грузов
  * Подписи грузов с массой
* 🚢 База типовых судов (Афрамакс, Панамакс, снабженческое, платформа)

## Запуск   py -m http.server 8000

⚠️ Начиная с этой версии в проекте есть 3D-модели судов (GLB), которые
браузер грузит через `fetch`. При открытии `index.html` двойным кликом
(протокол `file://`) Chrome и большинство браузеров блокируют такую
загрузку по CORS. Поэтому запускайте через локальный сервер:

```
cd deck-calculator
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

(или `npx serve`, или любой другой статический сервер).

1. Распакуйте архив
2. Запустите локальный сервер (см. выше) и откройте страницу через `http://`
3. Выберите тип судна
4. Добавляйте грузы и наблюдайте расчёты

## Исправлено: перемещение грузов по палубе

Груз не двигался, потому что начиная с three.js r120 `OrbitControls`
слушает Pointer Events (`pointerdown/pointermove/pointerup`), а код
перетаскивания в `scene.js` был написан под старые Mouse Events
(`mousedown/mousemove/mouseup`). Это два независимых потока событий —
`stopPropagation()` на мышином событии никак не блокировал события
указателя, поэтому камера вращалась и груз "ехал" одновременно и
бесконтрольно. Обработчики переведены на Pointer Events — теперь
перехват работает корректно.

## 3D-модели судов (Cargo Vessel / Multi-purpose Vessel VII)

Обе загруженные модели интегрированы в `models/` и подключаются через
`GLTFLoader`. Так как это сканы со Sketchfab без размеченного меша
"палуба", автоматически совместить их с расчётной плоскостью палубы
невозможно — поэтому слева появилась панель **"Калибровка 3D-модели"**:
масштаб, поворот вокруг Y и смещение по X/Y/Z. Двигайте значения, пока
модель визуально не "сядет" так, чтобы палуба судна совпадала с
плоскостью, на которой стоят грузы, и нажмите **"Сохранить для этого
судна"** — калибровка запомнится в браузере (localStorage) и подставится
в следующий раз для этого типа судна.

Сама расчётная плоскость (границы палубы, drag\&drop, ЦТ) как и раньше
управляется полями `length`/`width` судна в `js/app.js` — 3D-модель это
только визуальная подложка поверх неё, поэтому вся физика/расчёты не
зависят от того, насколько точно подогнана модель.

### Что стоит сделать дальше (руками, при желании)

* Подставить реальные length/width/deadweight для `cargo\_model` и
`multipurpose\_model` в `js/app.js` — сейчас там ориентировочные цифры.
* При желании "гулять" по палубе как по помещению (а не просто двигать
грузы сверху) — это отдельная механика (FPS/orbit-камера на уровне
палубы, коллизии с надстройками) и потребует доп. работы с геометрией
конкретной модели.

## Управление 3D-сценой

* ЛКМ + движение — вращение камеры
* ПКМ + движение — перемещение
* Колёсико — масштабирование

## Технологии

* Three.js (3D-визуализация)
* Vanilla JavaScript (расчётный движок)
* CSS3 (интерфейс)

## Примечание

Расчёты остойчивости упрощённые и предназначены для предварительной оценки.
Для инженерных расчётов используйте специализированное ПО (NAPA, GHS и т.д.)
